Privacy Policy

Last updated: October 1, 2026

This policy applies to personal OAuth applications operated by the site owner solely for access to the owner's own Google account and services.

Google user data accessed

  • Google Drive (rclone): files and folders in the owner's own Drive, as required for personal file synchronization and management.
  • Gmail (Gmail notifier): read-only access to messages and labels in the owner's own mailbox, including sender, subject, date, labels, and message body text.

Use of data

Google Drive data is used only to perform actions explicitly initiated by the site owner, such as listing, reading, uploading, updating, moving, or deleting files in the owner's own Google Drive.

Gmail data is used only to decide whether a newly received message should trigger a notification to the owner, and to improve that decision using labels the owner applies as feedback. The Gmail notifier does not send, modify, or delete mail.

Third-party processing

To provide notifications, the Gmail notifier sends limited message data to the following services, solely on the owner's behalf:

  • TypeSafe AI — sender, subject, and a truncated excerpt of the message body, used only to classify whether a notification is warranted.
  • Pushover — a short notification (sender, subject, and a link to open the message in Gmail) delivered to the owner's own devices.

Google user data is not shared with any other third party.

Storage

Processing records, such as message identifiers, classification results, and the owner's feedback, are stored locally on the owner's computer for the owner's private use. OAuth credentials and tokens are retained only as needed for that use and are not intentionally disclosed publicly.

Limited Use

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, not used for advertising, and not used by the owner to develop, improve, or train generalized AI or machine learning models.

Public availability

These OAuth applications are intended for personal, non-commercial use by the site owner and are not offered as a public service.
