Personal OAuth

This page describes personal OAuth applications used only by the site owner for private access to the owner's own Google services. The applications are not offered as a public service and are not intended for other users.

Current uses

  • rclone — synchronizes and manages files in the owner's own Google Drive.
  • Gmail notifier — a personal script that checks new messages in the owner's own Gmail inbox with read-only access and sends notifications to the owner's own devices for messages that appear to need prompt attention. It does not send, modify, or delete mail.
